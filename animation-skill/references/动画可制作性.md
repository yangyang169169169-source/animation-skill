# 动画可制作性：在剧本检查中加查

与母本校对并行，不另设“动画化必须改剧情”的步骤。输出证据、受影响资产／场次、保留剧情的办法、确需作者决定的变化。仅真实缺口阻塞其依赖。

非人生活、跨类资产及拟人程度变化按[物种生活方式与世界联动设计](物种生活方式与世界联动设计.md)将身体、居住通行、家具工具与原剧情功能一起设计。渲染媒介、身体拟人程度与社会修饰文化分别确定；不把3D理解为人类躯干，也不把贴近生物原型理解为没有职业和个性化妆饰。用户已明确授权的替换直接落实并记录保留边界，不重复申请；其他实质剧情选择仍按原规则处理。

| 检查 | 需要核实的具体问题 | 优先处理 |
|---|---|---|
| 物种与形态 | 剧本角色是人类、动物、植物、外星或其他形态；是否拟人、扎根／行走／漂浮、有无头颈、如何感知和发声；是否存在阶段／变身差别 | 依据正文先锁各角色真实结构和能力；空缺设计标为美术补充，不能自动改成人形或增加剧情能力；传给步骤2既有总纲与主菜卡 |
| 身体与操作 | 非人角色如何签字、握物、拥抱、扶人、开门、跳舞；翅、蹼、尾与衣服是否冲突 | 明确一套可复用的身体规则和持物接触点，必要局部参考；不临时添加另一双人手 |
| 表演与发声 | 内心活动是否有可见意图与反应；喙、口鼻、牙齿、眼睑是否能稳定承载对白 | 保留台词与信息释放，用具体姿态、目光、翅／手势和听者反应表达；不让每句都配密集微动作 |
| 视觉年龄与受众 | 成年关系是否被玩偶比例、幼态声画误读；角色原本是儿童还是成年 | 在造型与表演明确真实年龄，不因画风改年龄／关系或弱化同意边界 |
| 材质与接触 | 羽毛、长拖尾、雨湿、破损、奶油、水、镜面、多人遮挡是否出现难控交互 | 记录状态的发生与消失、身体层和服装层；优先正确母版与必要组件，不机械每状态重画 |
| 道具因果 | 断裂、挂钩、证书、签名、机构、数字是否必须被读懂 | 先锁定关键结构与证据对照；不把精确物件糊成装饰，也不加破坏操作教程 |
| 空间与尺度 | 门、桌、镜、舞位能否让实际角色行动；不同体型是否可读；邻室是否相邻 | 明确稳定地标、出入口及互补视角，按需求准备空场；不靠新增场景解释旧布局 |
| 动作与节奏 | 同一时间内是否有过多动作、对白、信息；群舞、机械、危险动作是否需层次 | 先安排动作准备、主动作、可读结果与反应，选择清楚的切点；不默认删句、压集或统一短时长 |
| 变形与夸张 | 哪些是设计弹性、哪些是剧情真实改变；伤害后果是否被喜剧动作抹掉 | 画风可以夸张，身份、伤势、责任和事件结果保持；不凭“动画”加魔法或无限复原 |

制作项记 `A-制作`，与E类剧情问题、S类呈现风险分别记录。先区分静态可设计、动态待验证、真实硬依赖。静态图看起来合理不证明它会运动、对口型或碰撞正确。

通常无需改稿：服装换材质、统一物种操作结构、镜头避开不必要的复杂交互、用同一母版表达轻微污损。需要作者决定：改角色物种、删改关键动作或台词、把伤害改成未遂、改秘密揭晓、为了容易生成而换因果机制。先准备具体最小方案，再集中交用户。
