# 迪士尼／皮克斯作品匹配与近期工艺

步骤1.7确定美术方向、每部剧首次制作资产之前读取。目标是让当前剧本找到贴切的3D动画电影对标，并吸收近期作品可见的工艺完成度。与[制作前参考研究与质量对标](制作前参考研究与质量对标.md)合用；用户已指定参考的职责与优先级不变，只维护Skill不制作项目。

## 先匹配这部剧，再借近期工艺

1. **从正式剧本提取美术需求。** 通读全剧，提炼核心情感／关系、喜剧或严肃程度、成人或儿童角色、年龄跨度、具体物种与拟人程度、现实／幻想机制、地区时代、社会身份、主要空间功能和关键材料。依据本剧情选参考，不能只见动物就选一部动物片，或见家庭就把成年主角设计成孩子。
2. **选择承担主要设计方向的作品。** 在用户允许的迪士尼／皮克斯3D动画方向内，优先找主题、形体和世界最贴近本剧的作品；可用少量辅助作品补人物、服饰、场景或道具的具体缺口。主次明确，资料少时先找够用的参考，不凑片单、固定数量或权重。用户已有明确画风图时，电影承担方法补充，不能取代该图。
3. **另核对近期可用作品的工艺。** 即使最贴切的主题参考较早，也查同系列较新作品或近期已公开的相关制作资料，学习毛羽妆发、织物细节、眼睑与表情、材料分离、色光和空间层次。主题造型与近期工艺可以来自不同作品，但每份参考只控制明确的维度，最后形成一部剧自洽的美术。优先近期合适的3D长片，不把较新年份自动判为更适合或质量更高。
4. **联网核实作品和素材性质。** 从[皮克斯官方长片目录](https://www.pixar.com/feature-films/)、[迪士尼动画官方影片目录](https://disneyanimation.com/films/)及[皮克斯研究资料库](https://research.pixar.com/)查当前可用作品与制作说明，记录本次核验日期。分清已完成作品、预告片、宣传图、概念图、设定稿、分镜和技术论文插图；公开预告不等于已上映，概念图不证明最终3D渲染效果。以当次真实来源核实上映／公开状态，不能把本页日期当永久最新。
5. **实际看图并转成具体设计。** 将主题匹配、选用理由、参考职责、看过的具体画面、可借优点、舍弃内容和实际提示词转译，合并到已有研究区／视觉总纲。保留当前角色、场景、道具条目的固定字段，不另建强制风格提案、审批或测试图阶段。已覆盖的研究可复用，同人换装和同场派生不每张重选电影。

## 题材与形式的查找入口

以下是截至2026-10-24核对官方页面后建立的研究入口；“适合借鉴”是本Skill的美术判断，并非工作室对本剧的推荐。每部剧仍需查具体画面与制作资料，不把片名直接拼成统一后缀，也不要求每个项目使用全部作品。

| 剧本需求 | 优先查找的作品 | 可选择的设计方法与适用边界 |
|---|---|---|
| 玩具、拟物、微缩日常、物件伙伴关系 | [《玩具总动员》系列近期入口：Toy Story 5](https://www.pixar.com/toy-story-5) | 研究物件身份与材料如何参与叙事、微缩尺度下的日常空间；分别查看成片／宣传画面与手作想象段落。不把玩具塑料反光套给皮肤、羽毛或织物，不把本页分镜／概念图当最终材质样张 |
| 老年主角、失落与陪伴、跨代冒险、有情感历史的住宅 | [《飞屋环游记》Up](https://www.pixar.com/upfilm) | 研究年龄、体块与姿态如何形成角色，居住物件如何承载人物历史，以及幻想景观的可信尺度；角色保持本剧年龄和身形，近期细节／渲染另找合适对标，不照搬方脸或气球屋 |
| 校园、学院、群像竞争、多物种机构空间 | [《怪兽大学》Monsters University](https://www.pixar.com/monsters-university) | 研究物种之间的剪影／体量差异、为不同身高设计的建筑，以及学院功能与气质；只借适用方法，不给本剧所有建筑加角和牙齿，也不把成年职业剧情变成学生故事 |
| 海洋、寻亲、不同水生物种与水下世界 | [《海底总动员》Finding Nemo](https://www.pixar.com/finding-nemo)、[Finding Dory](https://www.pixar.com/finding-dory) | 研究非人类表情载体、鳍与体块、水体中的远近层次及清楚剪影；水下空间、海面航海、岸上宫廷分别设计，不能只把背景染蓝或给鱼长人手 |
| 情绪人格、内心世界、成长中的复杂心理 | [《头脑特工队》系列近期入口：Inside Out 2](https://www.pixar.com/inside-out-2) | 研究情绪角色不同的形体、姿态与表情，以及现实和心理空间的视觉区分；特殊发光／颗粒材质只在本剧确有相应设定时借用，不把每个人都做成荧光皮肤 |
| 青春成长、家庭边界、强情绪、毛绒变身 | [《青春变形记》Turning Red](https://www.pixar.com/turning-red) | 研究有触感的厚实体块、夸张表情与毛绒轮廓、家庭空间的生活细节；成年角色保持成人年龄和吸引力，不全员圆幼脸、同款粗眉或同一青春配色 |
| 动物社会、都市阶层、职业／服装与物种共存 | [《疯狂动物城2》Zootopia 2](https://disneyanimation.com/films/zootopia-2/) | 研究物种口鼻、耳形、毛区与身形差异，衣装如何适应身体，以及城市空间尺度；保持本剧真实物种、年代与制度，不套原作角色脸、制服或标识 |
| 林地／湿地动物、生态冲突、人类与自然、科学变身 | [Hoppers](https://www.pixar.com/hoppers) | 研究动物结构与有感染力的表情、自然环境层次；外观概念图与最终3D材料分开核验。动物不因可爱就自动加人类衣装，科学设定和形态变化须有本剧依据 |
| 外星生物、归属感、宇宙幻想与异质生态 | [Elio](https://www.pixar.com/elio) | 研究不同物种与地区各有规则的形态和环境、亲切可读的表演与奇异材料；不全员换肤人类，不把每个星球都统一金属科幻或霓虹紫 |
| 元素生命、不同文化／阶层关系、奇异材料城市 | [《疯狂元素城》Elemental](https://www.pixar.com/elemental) | 研究材料本性、接触规则和情绪表演如何共同设计人物与城市；透明、火焰或流体效果只用于适用角色，不为好看改变普通人的物理结构 |
| 海面航海、岛屿文化、神话与宏观自然 | [《海洋奇缘2》Moana 2](https://disneyanimation.com/films/moana-2/) | 用于查海洋冒险、岛屿空间与服饰材料的具体画面，和水下鱼类故事区别；文化、衣装及神话规则服从本剧背景，不将热带风景套进所有海洋题材 |

## 近期工艺学习如何进入内置提示词

工作室名、渲染器或技术论文名只作来源，不能声称内置模型实际使用这些软件／算法。把可见结果转成当前资产能执行的形体、表情、材质和光照描述；不要求搭建工作室3D管线。

- **更新工艺仍保身份与艺术特征。** [Inside Out 2官方材质重建论文](https://research.pixar.com/docs/2024.SiggraphTalks.LEPXHKKA.pdf)描述了保留熟悉外观并更新技术的目标。对本项目转译为：升级毛羽、衣料与光色时，保护已定脸身、剪影和表情特征；特殊光效仍须让眼睑、目光和表情读得清，不用光晕遮脸。论文里的情绪粒子、发光边缘不作为所有项目的通用效果。
- **复杂世界内部仍有区别。** [Elio环境制作论文](https://research.pixar.com/docs/2025.BringingLifeToTheCommuniverseProceduralLookDevelopmentInPixarsElio.pdf)介绍了不同生态区与建筑细节的组织。对本项目转译为：每类空间有材料、结构与功能依据，大中小层次清楚，关键区域更精细；同一世界保持共同语法但不复制同一布景，也不为模仿论文自动添加动态灯光或视频任务。
- **新作品也可以有鲜明风格化处理。** [Toy Story 5官方制作说明](https://www.pixar.com/toy-story-5)将部分想象场景描述为手作粉彩方向。对本项目转译为：近期质量不等于增加写实度，最终媒介仍跟随用户已定3D方向；二维构图／概念稿可借轮廓与情绪，材质完成度另看适用3D画面。
- **细节分层而非全画面堆满。** 依[制作前参考研究与质量对标](制作前参考研究与质量对标.md)把粗中细轮廓、毛流／羽区、眼睑妆感、衣装工艺、多材料反射、接触与空间深度落实到当前执行词。与所选电影的适用优点对照实际图，不把多写形容词、分辨率或工作室名当达标。

## 每部剧的落地与复用

在现有研究／视觉总纲中简洁记录“本剧需求 → 主要作品与理由 → 近期工艺补充 → 人物／场景／道具各借什么 → 用户参考与母版优先边界”，附真实来源及核验日期。先形成清楚、一致的本剧美术，再展开各项Prompt，不为每个角色随意选不同电影导致同场风格分裂。

角色可借形体／表情方法，场景可借空间／材料方法，道具可借工艺方法，但共用本剧已定形状语言、比例与色光。用户另指定项目的影调／色调继续在该维度优先；新作示例中的紫蓝、荧光、颗粒或粉彩不能覆盖该选择。不同新剧按主题建立各自口径，不把某部天鹅项目的暖金宫廷、白羽或妆发当全Skill的固定世界。

生成后在步骤2—4原验收环节核对这些选择是否真正体现在图中；身份同质化、风格漂移、材料糊化、空间或证据错误按真实受影响项和有限返修处理。持续学习通过每部剧实际研究与可维护的规则记录实现，不宣称模型已被训练、已观看整部电影或已自动掌握所有新作，也不建立用户未要求的后台监控。
