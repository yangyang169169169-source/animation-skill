# 制作前参考研究与质量对标

在步骤1.7建立美术方向、步骤2—4开始新的资产批次前读取。本规则把用户选定的参考转成实际设计与验收，全部图片仍使用Codex内置image_gen；只维护Skill时不启动具体项目研究或生成。

## 参考各管什么

先实际查看用户给图、指定作品和本项目已认可资产，确认每份参考的职责。用户已讲清的分工直接沿用，写入现有Prompt文件的研究／视觉总纲或归档记录，不再增加确认轮次或另建顶层文件。

| 参考职责 | 控制内容 | 保留边界 |
|---|---|---|
| 用户开头指定的人物参考 | 动画媒介、形状概括、表情吸引力、毛羽／织物精细度与完成度 | 新角色按本剧剧情独立设计脸身；不全员套参考的脸、眼妆、发型或衣服 |
| 用户开头指定的场景参考 | 建筑与景观的动画体块、材质触感、细节组织、层次和空间深度 | 本剧地区、时代、地点功能、尺度与布局优先；不带入截图人物、字幕、水印或标识 |
| 用户另行指定的影调／色调参考 | 明暗关系、主辅色组织、冷暖、饱和度、光的柔度与材料本色 | 当用户明确另一个项目管色光时，该来源在色光上优先；不复制其人物身份、衣装、布局或错误结构 |
| 本角色／本场／本道具已认可母版 | 本人的固有脸身与物种结构、本场布局、该物件的外形及关键证据 | 后续造型或状态按真实依赖变化，不因新网络参考重做已定身份 |
| 联网找到的对标作品 | 补足当前资产有用的设计和工艺方法 | 服从用户参考及剧情，不用搜索结果取代已定画风 |

参考之间分维度取用，不求整张图全部一致。比如人物图的细羽与丝缎很好，但带紫灰照明，而用户指定另一项目的奶油暖白影调，则保留前者的造型／工艺、采用后者的色光；不把原图紫色眼妆当成所有角色的自然阴影。参考里的长颈裁切、重复视角、穿插、额外肢体或模糊纹理不继承。

不同题材与物种重新按本剧选择可用方法，不把前一部的肤毛色、身形、族群或职业配饰直接分发给新角色。场景的画风／材质参考也不等于固定影调：在用户明确控制范围内按当场剧情和时段转译情绪，同一工艺可以表现冷峻、压迫或安静，不把所有地点做成同一暖亮空间。没有新要求时不倒改已确认资产。

真实参考可访问时，在调用中按职责输入，并用完整英文说明保留与改变内容。先前实际看过但当前图片已不可访问时，只能沿用明确记下的观察并标注文字转译，不能填造路径或声称本次已传图；身份／证据等必须依赖该图的资产只停真实受影响项。图片和研究记录放资产目录之外。

## 每批制作前先做有用的联网对标

- 每部剧首次建立资产美术时按[迪士尼皮克斯作品匹配与近期工艺](迪士尼皮克斯作品匹配与近期工艺.md)，从正式剧情选择贴合的主要作品，再研究近期可用制作补足工艺。经典的题材／形体方法与新作品的细节完成度分工取用，用户已指定参考仍优先；不全剧乱拼多个电影风格，也不把这份候选片单当永远最新。
- 新项目、新角色身份、新场景类型或明显改变的美术方向，在写实际执行词之前联网寻找适合的电影、动画长片、动画短片或同类短剧案例，优先电影公司官方剧照、艺术设定、制作特辑和主创资料；流行截图可作线索，尽量查回作品及原始来源。选择与本剧物种、人物年龄、关系功能、地区时代和空间功能相近的可借鉴部分。
- 每批开始先检查已有研究是否覆盖本次需求。有充分有效研究、用户给图和已定母版时可直接复用；同人换装、同场派生和同物件状态不逐图重复搜网。确有缺口再补查，不为完成研究而付费试制、加生成数量或等待新的审批。
- 必须查看真正的参考画面；只读作品介绍或搜索摘要不算看图。记录可核实的作品／来源链接、实际观察、选用／舍弃及具体原创转译，合并在现有研究区。作品热度若无票房、榜单、播放或可信报道等依据，称“设计参考”或“优秀案例”，不虚称热门／爆款；用户给图不因无热度数据而失效。
- 参考多部作品中适合的轮廓、表情、服饰工艺、材料和布光方法，形成符合本剧情的原创组合；不原样复制既有人物的整套标志性造型，也不把不同渲染语言随意拼成一图。真人电影可用于服装、建筑和照明研究，最终仍按已定动画媒介转译。
- 身体拟人程度和生活体系需补足时，按[物种生活方式与世界联动设计](物种生活方式与世界联动设计.md)分别研究自然结构／运动、个人修饰和栖居／工具设计。二维截图可以只借体态、妆发或生活方法，已定3D工艺继续保持；自然资料不否定明确的奇幻修饰，电影里的社会能力、地域和全套建筑不直接搬入本剧。沿用有效研究，只有实际缺口再查，不增加固定试图或审批。
- 网页不可用或无法核实某图时如实记录，继续利用已可见的用户参考与有效研究完成独立工作；不能把联网失败写成研究完成，不能未经用户要求改画风或改用其他图片平台。

## 对标长片完成度，具体写入当前资产

以用户选定的迪士尼／皮克斯式电脑动画长片为设计与工艺目标。不能只堆工作室名、“顶级、8K、超细节”等词；先把大轮廓、体块与表演设计好，再写中尺度结构和有选择的微细节。“栩栩如生”落实为可信的重量、目光、情绪与材料触感，保留动画的概括和夸张，不自动变成真人皮肤、野生动物照片或过度写实的僵硬面孔。

| 对象 | 应进入实际执行词并在真实图检查的内容 |
|---|---|
| 毛发／羽毛／发型 | 依剧情、年龄、物种设计密度、长短、毛流／羽区、分组和轮廓；先大束和层片，再局部细纤维、柔软绒毛与克制边缘透光。头顶、面颊、颈身各有合理过渡，不一身同样的噪点、刷毛、硬刺或塑料片；发色有本色与自然层次，不能改既定毛色。适用时设计发缝、收束、鬓角、发饰连接和与衣装的接触 |
| 眼睛、眼妆与表情 | 依独立脸型设计眼眶、眼距、眼睑厚度、虹膜与瞳孔比例、眉／冠羽配合；视线聚焦、两眼朝向一致、高光克制。眼线、睫毛、眼影的位置、色彩和浓淡符合角色与阶段，妆色与照明分开；基准神情有内在意图与活力，不全员同款大杏眼、呆视或固定恶笑。没有相应器官的角色按自身表情结构处理 |
| 五官、脸型与身形 | 明确骨相／核心体块、五官布局、口鼻／喙、颊颌与额部差异，兼顾吸引力与辨识度；姿态、肩背、胸腹髋、肢体连接与承重符合年龄、体量和剧情。同人跨图保留比例，不能用大裙摆替代丰满身体或用磨皮抹掉成熟特征 |
| 服装与配饰 | 按身份和场次设计主辅强调色、剪裁、层叠、领袖／翼口、接缝、扣合与饰件连接；织物有厚薄、经纬／绣纹、垂坠和受力褶，缎面、哑光布、皮革和金属的反光各异。细节集中于身份重点且整套协调，朴素装也精良，不无理由堆珠宝或全身同一亮片。女反可依剧情略增饱和与利落线条，不用固定恶人脸替代设计 |
| 场景 | 先保证动线、门窗和物种尺度；按叙事安排前中后景、轮廓节奏与视觉焦点。墙面灰泥、石材、木纹、布艺、金属、玻璃和叶群呈现不同尺度与反射，接缝、倒角、局部磨损／手工感适合世界观，精致不等于做旧。真实光源、接触阴影、反射光和空气层次组织深度，材质细节清楚，不靠浓雾、过曝、过度景深或锐化遮错；空场不继承参考中的角色 |
| 道具 | 外形剪影、比例、边缘厚度、拼接／机械连接和实际材质成立；局部工艺与故事身份相配。关键文字、数量、断口、接口与证据最清楚，不用装饰、反光或浅景深挡住信息 |

细节应有主次并服务后续镜头。细毛、织纹与环境装饰不应压过角色表演或关键证据；不要求每个像素同样锐利，也不为增加微细节改变正式设定或把所有空间升级成宫殿。二维等其他指定媒介使用对应的笔触、色面和工艺层级，不套上述三维表面效果。

## 执行与验收

写词时把本条资产选用的参考优点落实为具体形体、毛发／妆发、材料、色光和构图说明，分别注明身份与风格输入。无需逐字粘贴本页全表，也不增加三份Prompt的固定条目字段。完整执行词与实际参考按[内置提示词与执行](内置提示词与执行.md)保存。

生成后按已有步骤2—4看真实图：整体是否符合用户参考、色光来源是否正确、角色是否独立且有神、材质与细节是否清晰可信、结构／布局／证据是否准确。关键质量缺口具体记录，按原授权与有限返修处理；不能因工具产出默认就通过，也不能为追求抽象“更完美”无限生成。场景／道具继续按实际清晰度保留原生文件，不把插值称原生高清。仅通过文字／链接核验不等于已达到长片效果；不承诺每次一次生成达到工作室成片水平。
