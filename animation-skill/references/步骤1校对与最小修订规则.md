# 步骤1校对与最小修订规则

步骤1的目标是找出会影响剧情理解或制作的真实错误，尽量保留母本情节与对白，减少用户重复核实。**检查全剧，报告聚焦；该报的重大问题不能漏报，不必要的改动不做。** 内容风险另读同目录的[内容安全与叙事边界](内容安全与叙事边界.md)。

## 一、先确定证据，不把创作选择当错误

1. 以用户指定的正式正文和仍有效的用户决定为依据。读取同项目已有修订记录，避免重新提出已回答的问题；若能访问相关历史反馈，优先提取用户决定，不把旧 AI 建议当作授权。用户本轮改变规则时服从本轮，不沿用旧的“全部逐项确认”。
2. 大纲、人物小传等辅助材料与正式正文不同，一切以正文为准，不区分辅助材料的新旧或是否曾标注“已确认”。在本轮工作副本中直接同步冲突的姓名、身份、关系、经历及情节概述，归类记录，无需用户逐项核实；不得反向改正文迁就辅助材料。客户原稿和归档备份保持原样，不重写无关段落，也不为缺失的辅助材料额外创作。正文未说明的内容不擅自补全；仅正文自身存在实质冲突，或不同正式正文版本的权威来源不明时，才按实际影响决定是否提交。
3. 完整阅读全剧，建立足以判断问题的内部时间、人物进出、秘密知情、关系和关键物件流转记录；不要求用户另审一套庞大底表。明显缺页、缺集或文件无法完整读取时如实报告范围，不能宣称全剧通过。
4. 疑点必须向前查铺垫、向后查解释。区分人物撒谎与作者事实、误会与真实身份、原书／预知／梦境与现实、闪回与当下、上集回顾与新事件、画外音／通话与实际在场。后续解释合理时，不提前补解释破坏悬念。
5. 分开追踪不同秘密：知道某人的特殊能力，不等于已经知道其身份、动机或另一项能力。形态变化不自动新增人物；成年角色变小不自动等于儿童。年龄确有生产意义且正文无法确定时再核实，不给全员编造年龄、血缘或出场。
6. 不把短剧的夸张、反派作恶、暧昧互动、开放式结尾或适度省略自动判为硬伤。只有省略造成无法成立的因果、误读或无法安排拍摄时才提出。

### 逐集对白数量与完整性（步骤1必查）

从第1集到末集分别检查，建立一集一行的统计与判断；仅受托部分集数时覆盖当次全部范围并明确未查集数。以权威正式正文的实际集界为准，不把场号当集号；先确认文件可读、分集完整和台词识别正确，缺页、OCR／解析失败或格式未识别记“未能统计”，不能报成零对白。

- **对白条数**：同一说话人一段连续发言记一条；排版换行不拆条，中英对照不算两条。不同人物轮流发言分别记。包括正文中的现场、OS／VO、通话及剧情内回忆角色台词；明确口播的内心独白、叙述性旁白另记，不能冒充人物之间的实际对话。歌唱、音效、场景动作、字幕、屏幕／文件文字、人物名和括号表演说明不当对白；引号本身不证明角色说过话。
- **文本量**：除条数外统计实际语言的正文量，剔除说话人、动作说明、空白与标点；中文用字数、英文用词数，并注明口径。双语对照按主语言统计条数，两侧文本量分列，不相加成双倍内容；真正混合说话的不同语言分别记录。不用物理行数或“嗯／好”等短回应的堆积掩盖实际内容偏少。
- **本集内容**：回顾、片头、下集预告和重复引用另标，不能靠它们掩盖本集正片没有对白；剧情内回忆的实际口播仍属于本集，不能误删。VO／OS是角色对白的发声方式；纯旁白推动的集数要注明其叙事形式，不能误称没有任何口播。
- **异常筛查**：零角色对白逐集复核；只有少量短回应、明显少于本剧常规及相近体量／功能集数、写有“对白待补”、说话人后为空、动作说“争辩／解释”却无必要台词、关键信息依赖未出现对白等均检查。不能只看相对排名：若全剧普遍很少，仍核对每集事件、交流与信息是否完整。条数和文本量是筛查证据，不设所有题材共用的最低句数／字数或自动补写指标。
- **判断与处理**：向前后集及本场上下文核查，区分有依据的默剧、动作／蒙太奇、情绪停顿、旁白叙事和疑似漏稿。合理少对白说明依据并保留；缺失影响关键剧情或需新增对白时按E0/E1提交场次、证据、影响及最小修复方案，不擅编台词、凑句数或改节奏。仅标签／排版误识别或一侧轻微漏译且原文完整唯一时按原直修规则处理，重新计数并复核。

将逐集表并入现有校对说明，不新增独立制作阶段或逐集审批。建议列：`集数｜有效角色对白条数｜中文正文字数／英文词数（按实际语言）｜旁白／内心独白及回顾预告说明｜结论与依据`；VO／OS可在备注标明。正常集简记，异常集给可定位证据和判断；未知数据不填0。修复后复核受影响集及前后承接，保原文与差异追溯。仅维护Skill不据此自动检查或改写已有项目。

## 二、三种处理方式

| 处理方式 | 适用条件 | 执行动作 |
|---|---|---|
| 需要用户判断 | 重大 E0/E1；会改变事件、对白信息、身份关系、知情顺序或关键镜头的取舍；较高内容风险 | 先完成证据核查和具体最小方案，集中提交；待决部分保留原文 |
| 直接修正 | 有必要修正，依据唯一，且不改变情节、对白意图、人设、节奏与关键打点 | 在备份后的工作稿修改，交付时按类别概述，无需逐条再批准 |
| 原样保留 | 可改可不改、仅审美偏好、不影响理解的小瑕疵；风险低且无需调整 | 不修改、不列待决、不以未处理为由阻塞交付 |

用户明确要求只检查、不改文件时，本轮只输出精简报告；可直修项仅作简短归类，不混入重大待决列表。用户已指定某项改法时直接执行，除非新证据显示会产生原授权未覆盖的重大影响。

### 需要用户判断的边界

- 重大逻辑或剧情硬伤：行动前提不存在、结果与既有事实冲突、关键伏笔丢失、重大时间关系无法成立。
- 对白／人物实质错漏：关键台词缺失、说话人归属影响人物动机、人物凭空出现或消失、身份亲属关系自相矛盾、关键翻译使剧情信息反转。
- 明显衔接与场景跳跃：人物或关键物件无法到达下一场，重复发生同一事件导致因果矛盾，跨集动作或秘密揭晓无法接上。
- 修复虽只改一个词，却决定婚约是否成立、谁开枪、谁知情、是否发生关键事件，也属于实质选择，不能以修改字数少为由直接处理。
- 原文缺少一个事实但不影响剧情，不提问；缺失事实影响重大且全文查不到唯一答案，说明不确定性和影响，不把猜测定性为硬错误。

### 可以直接修正的边界

- 错别字、乱码、多余转义符、明显标点与空格错误、无歧义语法错误、排版和已明确说话人的标签遗漏。保留角色口吻、口语省略、俚语、笑点和刻意不规范表达，不进行整剧语言升级。
- 中英对照的轻微错译或一侧漏译：仅在另一侧完整明确、说话人与对应关系无歧义、且无需增加剧情信息时忠实补正；正文原语对白优先。双方含义冲突、整句两侧都缺失或会改变关键信息时，提交 E0/E1，不能自行编对白。
- 依据上下文唯一、与关键剧情无关的小动作或标签错误，例如已站着又无缘由“站起”、同一连续动作的器物名称笔误。若涉及真实进出场、物件交接或关键行动，不擅自补动作解决。
- 实际场景标题缺少时段时，依据连续剧情补明昼／夜／清晨等；场号漏号、重复号按实际场次补正。不因标题缺失新增事件或机械拆场，不编造日期、孕周和时间跨度。不明且不影响剧情的时段保留不确定，必要时标“时段未明”。
- 用户已明确排除的制作说明、版本标记等可移出正式正文；清除显然误混入的纯编辑残留。不因出现“下集”就删除角色台词、旁白或有叙事功能的集尾钩子。

“语言格式直接修”不等于“对白可以重写”；“轻微错误直接修”也不等于“所有 E0/E1 都可按自己的理解处理”。若不修改也没有实质影响，保留原文。

## 三、精简报告，让用户只判断实质选择

默认交付修订工作稿与一份校对说明；项目已有对应记录时沿用，不机械新增多个重叠报告。只读任务不生成修订正文。说明使用以下结构，空的待决表不必保留：

```markdown
权威输入：[文件与版本]；实际审阅范围：[集数／缺失范围]。

### 逐集对白数量与完整性
逐集列出统计表，注明计数语言与口径、合理例外及未能统计的真实范围；异常的证据和处理并入下方相应栏目。

### 需要用户判断（N 项）
| ID／级别 | 场次与前后文证据 | 为什么影响剧情或制作 | 建议的最小改法 | 影响范围 |
|---|---|---|---|---|
| L-01／E1 | 引用互相矛盾的两处原文，标出集／场及可定位位置 | 说明观众理解或拍摄会受什么影响 | 给出具体原句→拟改句／动作；有实质分歧再列必要选项 | 列出关联场次 |

### 已直接修正
按语言格式、明确标签、轻微连续性等归类概述；说明是否有正文对白增删或语义变化。

### 复核与可用范围
说明全剧覆盖、修改点前后衔接及尚受重大问题影响的范围。
```

- 同一根因合并一项，列全受影响场次；不要让用户为同一个时间线决定回复十个编号。不同根因不可为了减少数量而藏在同一项里。
- 建议必须足够具体，优先给一个推荐最小改法；只在确有不同剧情走向时给少量备选，不把写方案的工作退给用户。
- 不提交已直接修正项的批准复选框，不要求用户回复“全部同意”才使小修生效。详细差异可随修订留存供追溯，但不成为新的必审清单。
- 可选优化及无需修改的低风险项不列“未处理问题”。已有旧问题表无需全部转抄为待决：已回答的沿用，纯建议移出待决，仍真实影响重大的保留。
- 若没有需要用户判断的问题，直接写“本轮未发现需要你判断的重大问题”，交付实际完成范围；不能把这一结论写成“保证无逻辑错误／平台零风险”。

## 四、最小修复与验收

1. 保留不可变的本轮输入和修改前备份。修改由模型逐项判断与撰写；程序用于读取、差异对照、统计和校验，不用于批量创作或以全局替换推断剧情。
2. 对实质问题先确定最小修改集合，再按授权改动。优先局部词句、动作或场景标签；不顺带润色相邻段落。涉及对白与人物的信息变化必须有对应依据和授权。
3. 每处修改向前、向后核对关联场次；处理必要连锁影响，但不把局部授权扩展为整剧重写。尤其检查时间用语、左右伤势、人物位置、物件持有人和秘密知情是否仍一致。
4. 对照本轮输入检查集数、事件顺序、场次、对白与说话人。统计只用于发现遗漏；对白数量相同仍须检查具体文本变化。每一处新增、删除、改义都应能归入默认直修或既有授权，发现越界改动应撤回。
5. 完整审阅且未决重大问题已解决后，交付可用正式稿；默认直修范围不再增加冻结确认。若仍有重大待决，交付已修工作稿并标明范围，不把未决方案写进正文冒充已确认。
6. 不为低风险或可选项阻塞整个项目；也不以用户未回复代替重大决定。后续生产仅在已获步骤授权和可用范围内执行。

## 五、容易误判的实际模式

| 情况 | 应采取的判断 |
|---|---|
| 大纲或人物小传中的姓名、关系、经历与正文不同，即使辅助材料更新或曾确认 | 一律以正文为准，直接同步工作副本中的辅助内容，不要求用户重新选择，不反向修改正文 |
| 人物听懂“不能碰”，但不知道为什么不能碰 | 可成立的误会，不补解释，不当作知情矛盾 |
| 上集枪响，下集从另一个角度接同一发子弹 | 先判断是否承接同一事件；不自动新增第二次开枪或删掉钩子 |
| 同一晚的对白出现 Yesterday，但是否跨日影响后续发布会 | 查全时间链；牵动重要日程的时间改法列 E1，并给联动范围 |
| 女主只知道对方察觉自己心虚，改成知道读心能力更通顺 | 保留原知情边界；后者会改变主线，不能当润色 |
| 场景标题缺“夜”，正文已明确连续深夜行动 | 补标题，无需询问；不新增场景或改变行动 |
| 缺少一位人物的年龄，正文没有需要精确年龄的情节 | 不编年龄，也不为补齐人物表要求用户核实 |
| 打斗只写受伤与人物反应，没有伤口细节展示 | 不逐条列风险；若明确要求伤口、直接伤害过程等风险内容特写，按安全规则提交具体最小呈现方案 |
