# 人物选角与跨剧差异化

适用于步骤2的新角色设计、人物 Prompt 和人物图片验收。人物资产的追求是每部剧的每位主角都因剧本而成立，有独立的面孔、眉眼、气质和风格，尤其女主及主要女性角色；先联网研究优秀人物参考，再原创设计，并让同剧配角从头发到五官轮廓都能与主角清楚区分。与同目录[角色资产生成规则](角色资产生成规则.md)配合使用；不改变剧本、不自动返修历史资产、不增加生成授权或另设重试次数。

## 动画转译边界

本文件完整保留蓝本的研究、原创转译、同剧至少五项可见差异及跨剧对照流程。步骤1已定画风优先；非人角色的鼻唇／头发维度改为口鼻／喙、冠羽／耳角／鬃毛等适用结构，不强加人鼻、人唇或人类发型。同物种同色、亲缘、身体体量按正文保留，不为凑差异强改颜色或瘦身。真实人物资料只研究姿态、比例、表演和审美优点，最终生成的是原创动画角色；动物不因参考真人而长成人脸。

**适用结构优先**：先按[角色资产生成规则](角色资产生成规则.md)确认物种、生命阶段、拟人程度、身体与表情结构。本文件的“选角／面孔／眉眼／头发／服装”是沿用蓝本的规划术语，均按该角色真实存在的身份结构转译；不要求植物、外星或其他角色具有人类五官、性别体型、衣装或人类站姿。无头角色的“脸部钩子”可以是已有核心纹样、花冠轮廓、感知器官等记忆点；不能为填栏目补出不存在的头或眼睛。

## 1. 从人物设定选类型，再设计面孔

- 以正式正文中的年龄、时代地区、身份经历、性格、关系表现及用户视觉要求为依据；明确写出的外貌优先保留。未写明的部分由美术设计补足，不把设计推断写成原文事实。
- 为女主选择一个主要外貌类型，必要时加一个辅助气质，说明对应的具体剧情或行为依据。甜美、可爱、冷艳、淑女、纯欲、熟女只是可选方向，可以使用明朗运动、知性干练、英气、中性、异域古典或适合本剧的其他类型，不按项目轮流抽签，不把所有词堆在同一个人身上。
- 外貌类型不等于固定性格或道德：坚强女主可以甜美，温柔女主可以冷艳；单亲母亲不自动等于熟女，财阀不自动等于冷脸。不要为了差异改变角色年龄、族裔、关系或剧情，不用族裔替代五官设计。
- 男主与其他主要角色同样定制，可按人设选温润儒雅、阳光少年感、冷峻克制、硬朗成熟、斯文知性等方向，再设计具体骨相和五官，不能所有剧都套方下颌、深眼窝、背头的同一俊男。

下表只说明如何把类型转成可见设计，不能作为跨剧重复使用的固定选角模板。每次须重新组合与本剧相符的特征：

| 类型方向 | 可转成的视觉设计 | 避免的误用 |
|---|---|---|
| 甜美 | 柔和的面部转折、舒展眉眼、亲和的眼神与唇角；脸型可圆、椭圆或其他适配形状 | 全部写成同一张大眼尖下巴娃娃脸 |
| 可爱 | 灵动眉眼、较柔和的颊部体积与轻巧表情，保留实际成年年龄和自然比例 | 把成年角色幼龄化，靠夸张大眼代替设计 |
| 冷艳 | 清晰骨相转折、克制的眉眼与表情、利落轮廓；不必同时细眼薄唇 | 把美感自动等同于恶意、冷酷或反派身份 |
| 淑女 | 协调舒展的五官、端雅仪态与适合时代的整洁发型 | 只换礼服或珠宝，面孔仍沿用其他主角 |
| 纯欲 | 成年角色的清透自然妆感、柔和眼神与克制的唇部质感，结合角色真实关系表现 | 用暴露、夸张挑逗姿势或儿童化五官代替类型 |
| 熟女 | 与真实年龄相符的成熟骨相、沉稳目光、从容姿态与细腻的动画皮肤／毛羽层次 | 精修成二十岁模板脸，或靠眼袋病容硬造年龄 |

## 2. 先联网找选角参考，再原创转译（新身份必须先行）

### 按剧本建立检索方向

- 在原选角简报先写“物种／形态＋拟人程度＋生命阶段＋角色关系功能＋指定画风＋受众”，再选检索词。优先找同种或结构相近、叙事功能相近的优秀动画短剧及动画作品，不只搜人类男女主，也不把所有非人都归入“可爱动物”。有眼神才研究眼神，有衣装才研究服饰；原文事实与美术补充区分。
- 为男女主、核心恋爱对象、核心反派和高频核心配角分别提炼选角简报：真实年龄段、时代地区、明确外貌要求、主要类型、剧情中的关系作用、气质气场及眼神表达。尤其主要女性角色，不只搜索“beautiful woman”“美女”或沿用上一部剧的候选名单。
- 用“年龄感＋外貌类型／关系气质＋人物或角色形象＋具体视觉目标”组合检索；需要时用目标地区语言或英文，补充如自然肖像、角色定妆、短发造型、眉眼特写等词。职业用于判断适配性，不自动绑定固定脸型。多名相近年龄女性不能都用同一组泛化搜索词。
- 检索与实际看图是角色设计的一部分，在已授权的人物规划或 Prompt 工作内自主完成，不额外增加确认轮次。这里的联网研究不自动授权图片生成。

### 找同类型、受众认可且可看清特征的图

- 优先同类或类似的优质、受欢迎动画短剧角色设计，结合本剧画风比较其轮廓、体块、表情载体、肢体／分枝、表面材质、配色与镜头辨识度。可核实的官方作品页、创作者原发布与制作设定资料优先；未找到相近短剧时，可用动画长片／系列、官方概念设计和真实生物结构资料互补，并说明匹配与不匹配处。真实生物资料辅助结构，不能把项目指定动画画风改为自然摄影。
- “爆款／高播放／热门”只在确实查到平台原发布数据、榜单或可靠公开报道时使用，附来源与查询日期，说明证据适用的作品和范围；作品受欢迎不等于已证明某个设计导致成功。没有可靠数据时写“设计参考／美术选择”，不编造热度、排名或用搜索排序当证据，也不把热度研究变成额外排名报告。
- 使用当前可用的网页与图片检索工具，寻找符合本剧设定、具有镜头吸引力的优秀动画角色、官方角色概念图、对应生物结构与服饰资料；真实人物肖像只作辅助表演与比例研究。优先有来源、作品可核实的官方动画剧照、设定图、制作资料及清晰生物影像，不把来源不明的 AI 美女合集当作真实大众审美依据。
- 每个新主要角色通常先比较约 3–5 个候选、至少不围绕单一人物锁死；数量是研究起点，不是固定配额。有足够差异和适配证据即可收敛，没有适合的则调整检索继续找，不为凑数收图。各主要角色分别找适合自身的参考，不能整剧都从同一演员或同一套脸型衍生。
- “大众喜欢”须结合目标受众和具体角色类型判断。用确实查到的作品受欢迎情况、公开评价或受众反馈解释选择；名气与人设适配分开看。只有审美判断时明确写“美术选择”，不因搜索排序靠前就宣称大众认可，也不要求额外做受欢迎度排名。
- 必须实际查看入选参考图片的像素，观察适用的核心结构、附属形态、材质和表情；人类再看骨相、眉眼和发型。不能只根据名称、网页介绍、搜索摘要或图注填写视觉结论。优先完整轮廓、关键结构近景与多角度可比视图；强滤镜、彩光或夸张表情只研究可见优点，不据此推断被遮蔽的结构与固有色。实际看图工具不可用时如实记限制，不伪造已查看。
- 在 `character_prompts.md` 规划区增加 `## 选角参考与原创转译`，每个角色用紧凑条目或表格记录：角色与选角简报、参考对象／角色及作品、来源页面与实际图片链接、已查看的视觉特征、选用与不选用的理由、具体借鉴部位、最终原创设计与区别。必要缓存只用于授权研究，按项目归位；不强制下载整套参考，不伪造图片路径或看图记录。
- 工具联网失败时先尝试当前可用的其他检索／看图路径；用户已提供的适配参考或已有核验资料可以替代并注明。没有实际看过的可用图时可继续读剧本和做暂定规划，但须标记“选角图片研究未完成”，不把文字检索冒充完成，也不直接启动该新身份的首图生成。用户当次明确要求离线或跳过研究时，按其范围执行并记录限制。

### 借鉴优点，设计本剧自己的面孔

- 把观察变成自己的设计决策：例如保留某类生物的重心与肢体节律，吸收某参考的形状对比或羽毛／叶片细节层级，再依据本剧角色功能重设比例、轮廓、纹样与配色。不照搬一个知名角色的整套剪影、脸部、衣装和颜色组合；不会因为热度高就牺牲剧本物种、指定画风或本剧辨识度。
- 可以借鉴参考人物的脸型骨相、眉形毛流、眼型眼距、鼻唇比例、发型发色、气质气场、眼神和仪态。将“哪里好、为什么适合本剧”写清，再判断该特征是否与本剧年龄、人物经历和其他角色设计兼容。
- 以多个互补参考形成设计方向，选择性吸收、重新协调成一张自然完整的原创面孔；不把几个人的五官机械拼接，也不照搬单一明星或影视角色的整套面孔、头发与表情。没有固定百分比或必须借用几个人的规定，最终整体协调与辨识度优先。
- 参考对象／作品名留在研究记录，最终 Prompt 写本角色的具体视觉特征，不用“像某某演员”“某明星同款脸”代替设计，也不反复将固定明星姓名写进所有角色的正负提示词。实际上传参考图时明确仅借鉴的部位或造型，不能把研究图片标成“面孔锁定母图”；无此需要时以文字转译即可。
- 同一参考可在确有理由时贡献某个局部优点，但不得反复沿用相同的整套参考组合，让每个女主都呈现同一骨相、同一眉毛和同一眼神。检索名单不同也不等于设计不同，须检查最终吸收的特征是否又回到默认模板。
- 在现有主菜卡中写明最终气质气场和目光的可见表达，例如眉眼松紧、注视稳定度、眼睑开合、唇部张力、头颈姿态及从容／警觉／亲和的表达；这些可以服务本剧表演，但不依赖夸张表情才能辨认身份。基础板仍保持自然表情，骨相五官独立成立。

## 3. 写出可执行的脸部与头发设计

在现有角色视觉主菜卡、脸谱差异表中补充即可，不额外创建固定档案或站位图：

本节同时按[角色剧情驱动与造型差异](角色剧情驱动与造型差异.md)逐项落实毛发密度／毛流分组、发型发色、脸型与五官布局、目光、适用眼妆、自然表情及真实身体比例。分清身份底层、阶段妆发和当场表演：不靠妆容／眼色／不同衣服掩盖同一张底子；不将所有角色精修成相同的脸或身形。色调借用与脸身身份分开，参照[色光与材质基准](色光与材质基准.md)。

非人角色将下列人类维度映射到自身已有结构：脸型／骨相→核心体块及识别轮廓，五官→实际表情／感知结构，头发→已有冠羽／分枝／触须等附属形态，衣装→适用服饰或稳定外形／纹样。具体结构由剧本与美术方案确定，例子不是通用器官清单；没有的注明不适用。至少五项差异继续从适用结构中比较，剧情相似与同色约束优先。

- **外貌类型及依据**：主类型、必要的辅助气质、原文场次或人物设定依据；未写明的选择注明美术设计。
- **脸型与骨相**：面部长宽、额头形态、颧骨位置与转折、下颌宽度和下巴形状，给出能整体辨认的轮廓。
- **五官组合**：眉毛的浓淡、粗细、长短、眉头形态、眉峰位置、眉尾走向与毛流，眉眼距离、眼型与眼距、眼睑及眼尾结构，鼻梁鼻头鼻翼、唇峰与上下唇比例；眼色可辅助，不能代替结构差异。不要全员都写同款细长平眉、大杏眼、高窄鼻、饱满唇和小尖下巴。
- **头发**：明确发色的实际色调、长度、直卷、分缝、刘海、额头露出及外轮廓；不能只写“长发”“深色头发”。发型须符合时代、职业、剧情阶段和连续性。
- **辨识重点**：选出最能在自然表情、少妆及中近景下认出的骨相与五官特征；衣服、妆容、表情和精修不能替代这些身份特征。
- **气质气场与眼神**：除类型标签外，明确人物惯常的目光、眉眼张力、姿态与镜头存在感及剧情依据；别让所有女性都是同样温柔清透、所有男性都是同样冷峻深邃。角色变化可通过表演和造型表达，不能让同一角色换装后换脸。

## 4. 同剧配角与主角必须清楚区分

- 配角逐一对照男女主，尤其女主／女配／女反、男主／男配／男反及经常同框的角色。沿用现有至少五项明显差异的要求，其中脸部体块、适用五官组合、发型／冠羽轮廓与色彩均须核对；剧情锁定同色时保留，以其他适用维度拉开差异，不能靠年龄、气质标签或服装差异凑数。
- **发型和发色分别核对**：人类角色或有对应结构的物种按本条区分；剧本锁定同色毛羽则不强制改色。避免同一发色、同一长度、同一分缝和同一卷度的近似组合。发色差异应在中性白光下可辨，不能仅把“深棕”改名“巧克力棕”；发型要有明显轮廓差异，不能仅换一枚发夹或梳发方向。
- **五官轮廓独立设计**：配角使用明显不同的面部长宽、颧颌轮廓及眉眼鼻唇比例组合，不能把主角的脸换发色后当另一个人。相同类型也可以有完全不同的面孔，不强制配角变丑来衬托主角。
- 剧本明确要求亲缘相似、双胞胎、替身或伪装时，记录相似的剧情用途和范围，保留必要部分；在不破坏剧情的其余特征中设计区别。剧本或用户锁定相同发色时保留发色，通过发型和五官拉开距离，不擅自改设定。
- 普通 NPC 在既有规划或 Prompt 中简写有效差异即可，不因此新增主角级主菜卡、独立图片或造型套数。

## 5. 跨剧主演对照

- 新剧首次设计主演时，优先查本生产根目录中可访问的近期已完成项目，选与当前主演年龄、类型或脸部描述最接近的少量项目作对照。先读既有 `character_prompts.md` 的主角类型和脸谱设计；有真实图片时查看已确认的清晰面孔，不只看文件名。无需遍历所有历史项目。
- 在当前 `character_prompts.md` 的规划区简记“跨剧主演对照”：实际比较的项目／角色／参考、重合风险、当前采用的骨相五官与头发区别。仅看过文字就写“文字对照”；未取得图片写“图片相似度未核验”；无可用历史资料时如实记录，不编造已排除撞脸，也不阻断独立设计。
- 同一甜美或冷艳类型可以跨剧出现，但不能重复同一套脸型骨相、眉眼鼻唇比例和头发组合。发现重合时优先调整本剧未锁定的骨相与五官设计，再配合头发，而不是仅改服装、眼色或妆容。相似度以实际视觉辨识为准，不编造数值阈值。
- 对照时也检查近期主角的选角来源组合、眉毛设计、眼神与气质表达，防止换了参考姓名却仍做成同一种风格。每部剧的新主演应有本剧专属的整体选角方案；不要求全世界从未存在的五官，也不以破坏人设来强行求异。
- 新角色首图不得绑定别剧主角为身份参考，不复制历史面孔锁定段落；历史资产只能用于区别对照。用户明确要求同一演员／角色延续时按其要求复用。同一剧的已确认角色则继续锁脸，跨剧差异规则不能造成跨服装身份漂移。
- 本次规则更新只作用于后续新建及获授权修订的角色。旧图可作对照，不自动重生成或把所有历史资产标为失效。

## 6. Prompt 与首图验收

- 每条最终角色Prompt先写具体物种、形态阶段与拟人程度，再落实研究后原创的核心剪影、实际身份／表情结构、肢体数量与连接、固有材质／色彩，以及确有的服饰和指定动画风格。人类或具对应结构的角色再写具体骨相、眉眼、鼻唇、发型与眼神；没有的删除而非生造。类型词只辅助描述，不能只写“甜美女主”“冷艳美女”“handsome man”或“可爱植物／外星人”就出图；差异必须出现在实际提交正文中，并能对应研究记录中的设计选择。
- 配角 Prompt 用正向描述明确自己的五官和头发；不能仅写“不像女主”。精修保留已设计的轮廓、五官比例、自然不对称及成熟年龄特征，不把所有人磨成同一张光滑美人脸。
- 主演首图通过后再扩展造型。首图验收同时检查：类型是否符合本剧人设、参考中选用的优点是否自然落实、骨相五官眉毛及气质眼神是否有独立记忆点、是否过度贴近单一参考、与可用历史主角是否明显撞脸或整体风格趋同。同剧配角基准须与主角的清晰正面头部特写比较，核对发型、发色与五官轮廓是否分别可辨；自然表情与少妆仍应能认出不同的人。必要时用现有清晰头部特写并列比较，不额外生成测试图。
- 并排先看头脸轮廓、五官布局与口鼻比例，再看毛发轮廓／分组和身体体量，最后看妆发衣装与色光；检查表里写了五项不代表实际图已拉开。自然表情和弱化衣色的观察仍须可辨，不能伪称做过灰度／去妆测试或填造相似度数字。藏身份、亲缘与同色体型约束按剧情保留。
- 提示词写得不同不代表实际图已不同。明显撞脸或头发相似时先定位是设计趋同、错误身份参考还是模型没有落实，再修受影响角色的未锁定设计／参考；在既有授权和返修规则内处理，未通过的母版不扩展依赖造型。不自动返修已合格角色，也不增加重试额度。

非人角色的首图与派生验收同时核对物种／形态、实际结构、轮廓辨识、指定画风、材质美感和后续动作用途；有头的对比清晰头部，无头的对比规划中的身份核心与全形。用户参考及已合格母版可复用，不为换装重新搜同一身份，也不为研究增加无用途测试图。
