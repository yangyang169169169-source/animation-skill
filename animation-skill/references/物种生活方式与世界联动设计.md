# 物种生活方式与世界联动设计

步骤1确定动画方向，以及步骤2—4涉及非人角色、新世界或用户明确改变拟人程度时读取。目标是让人物、场景和道具像同一群生命真正生活与使用的世界，兼顾角色吸引力、个性与原剧情。人类项目按自身时代文化与生活逻辑设计，不为套用本规则强加动物习性。

## 1. 先确定形态与生活规则

动画媒介、身体拟人程度、表情夸张和社会生活的拟人程度分开决定。精细3D不等于真人身体，较自然的动物体态也不排斥虚构社会中的职业、理毛、妆饰和衣服；用户指定高度拟人的社会时不擅自退回野生生态。优先采用用户明确方向和正式设定，空缺在现有视觉总纲内作为原创美术补充说明。

先写角色从正面和侧面都成立的主要体块、器官连接、支撑、重心、移动与操作方式，再写衣装。不能只把物种名称放在同一人类躯干前面。四足、翼、鳍、枝根等按已定世界使用，不为握笔或穿衣临时长出第二套手臂；奇幻操作能力需有既定依据。丰满、强壮、瘦长及年长按该形态真实体量表达，不用裙撑代替身体，不给非人硬补乳房、细腰或人类长腿。

在原有总纲／规划中记录适用项即可，不另建必交档案：

| 依据 | 设计需回答的问题 | 三类资产共同落实 |
|---|---|---|
| 身体及感觉结构 | 怎么看、触及、转身、休息与保持平衡 | 身体母版、视线高度、入口与操作面 |
| 移动与活动环境 | 行走、游动、攀爬、飞行或扎根怎样切换 | 可用通路、停靠／支撑区、转弯及起落空间 |
| 生活与职业文化 | 居住、睡眠、进食、梳理、工作、学习与医疗怎样发生 | 合身家具、收纳、工具接口、照护设施与个人用品 |
| 剧情必须保留的机制 | 哪个动作、接触、声响、证据或笑点不能消失 | 功能区域、道具结构、状态和信息时机 |

生物资料帮助理解自然结构，动画参考帮助艺术化概括；虚构染色、妆饰和职业用品不冒称自然物种特征。参考作品的地域、社会与能力不自动迁入本剧。

## 2. 自然形体与个性化修饰同时成立

在[角色剧情驱动与造型差异](角色剧情驱动与造型差异.md)的身份底层上设计适用的个人修饰，不把“像真实动物”理解为全员无妆、素色和同款短毛，也不把丰富理解为给全员加满装饰。

- **毛发／羽冠造型**：根据本人性格、年龄、职业与习惯选择卷直、分缝、蓬贴、梳向和主束节奏。允许世界设定内的烫卷、拉直、理毛及局部染色；写明根部与末端、色区范围、过渡及养护状态。生长连接仍成立，不用悬空假发块替代真实附属结构。
- **颜色分层**：分别锁定天然本色／纹样、人工染色、妆色、衣装与环境光。只染冠毛不等于整身换物种；用户明确改种属或全身本色时落实对应自然识别结构，不能只换衣服颜色。不用白、黑或鲜艳程度判断善恶。
- **眼部与年龄感**：眼形眼位、上／下睑体块、褶皱、睫毛分布和目光张力共同设计；成熟可用适度结构与仪态表达，不自动加病容。睫毛长短、眼睑褶或妆浓淡没有固定年龄与性别公式；成年小个体不变幼体，儿童仍保实际年龄与适龄修饰。
- **妆饰与五官**：眼影、眼线、口唇或喙表妆膜按真实载体、材质、轮廓及场合呈现。硬喙表面着色仍是硬喙，不能画出人唇、牙齿或不存在的眼窝。无此修饰文化或器官时不强加；男性、女性与配角均有自身设计空间。
- **衣装与配件**：剪裁、开口、扣合和佩戴支点适配真实身体及动作。翅根、鳍、四足、尾部、长颈等按既定结构留空间，衣物不遮没物种剪影、不让附属肢体凭空消失。用面料、工艺、局部配色和合身轮廓表现身份与审美，不把所有职业统一成人形西服或所有非人改无衣。

每名可辨角色选择少量协调、远近层次明确的识别组合；近景妆点和小饰件补充身份，头脸、身体与头部轮廓仍承担主要区别。主角要有适合剧情的独特吸引力，配角保持同等工艺质量，但不竞争同一套主角轮廓。具体颜色、物种、妆发和配饰属于本剧设计，不传播为通用分配表。

## 3. 空间要体现使用方式

以“由谁建造、怎样到达、如何使用”为起点设计居所、公共空间与工作场所，先解决通行、支撑、操作、视线与活动，再选择建筑、材料和装饰。不同阶层、职业、地域仍有各自生活文化，不把同一物种全做成同样的洞穴、巢或宫殿。

世界特色必须作用于基础设施和日常用品。按本剧需要，检查道路／水路／空中层、进出接口、家具高度与承托、睡眠方式、食器、梳理区、工作台、收纳及医疗空间。没有剧情用途的项目不机械全部设计或生成。只在人类办公室加动物纹章、在人类卧室放一只装饰窝、在普通城市旁加水池，不能代替物种生活设计；已定人类式社会则保其合理约定，不强行去人类化。

区域过渡要可用：例如干湿、内外、地面与高处、公共与私密之间，身体和必要物件如何通过，在哪里停下或操作。遇到水或潮气时，纸张、布料、电器及需要地面反馈的动作按剧情安排合理条件；不能为贯彻主题让所有区域变成同一种介质。环境图保持空场，以门槛、坡面、支撑面、工具槽及相应尺寸表达用途，不加角色来掩盖设计。

选择与世界、地域及使用者相符的材料、连接与形状语言，材料精细但有主次；少用贴满物种图案或过度象形来表示“专属”。同世界可有朴素、正式、奢华与工作场所差异，不能用统一豪装或滤镜抹平。日夜天气和情绪影调仍服从本场真实条件。

## 4. 道具先保剧情功能，再做形态转译

对需要转译的关键物件，在现有调用表连起“原文／已获授权 → 使用者与动作 → 新形制与接触点 → 触发及可见结果 → 数量／状态／证据”。写清可触及部位、支撑或握持位置、相对大小、材料与必要接口，不能只把普通物品加羽毛或换纹样。

外形改造必须保住所需功能：长短、软硬、滚动或停驻、开合与遮挡、声音反馈、承托、断口与对合、签字及文字来源等。有关联的衣物、物件和场景共享实际材质、接口、尺度和状态；同一物件在场景里出现时优先真实输入其母版，不靠同名保证一致。

按功能区分实例。私人用品、客用物、医疗设施可能有相同物种适配方式，却不是自动共用的一件资产；依归属、材料、卫生／支撑、尺寸与剧情功能判断是否需要独立母版。环境内已有且无需独立镜头的物件仍可由场景承载，不为联动规则增加无用途图片。

**不能为世界设计默改剧情。** 水上通行不自动删除原有车辆或落脚动作，睡眠设施变化不抹去承托、移动和隐私事件，工具变化不丢失长短笑点或证据意义。用户已明确授权的视觉替换直接落实并登记边界，不重复要许可；未获授权的关键动作、物种或因果改变，先提出保留剧情的具体方案，只暂停真实依赖。正式稿、视觉执行说明和已授权改稿分开保存，不让新资产倒改原文。

## 5. 联合检查，阻止局部漂亮而整体失配

实际英文Prompt将本项的身体／生活规则写成可见结构，按用途说明通行／操作／支撑区域、材料和剧情必须保留项，删除与新方向冲突的旧模板句。角色三字段、场景／道具两字段及文件目录不变；不复制本页全部清单到每条词。

已有本批实际图时联合查看：角色的体量、动作接口与衣装是否匹配空间和工具；各地生活方式是否一致又各有用途；同物件的场景版本是否漂移；是否混回不适用的人类家具、错误旧身体或旧世界母版。图片漂亮、英文Prompt写了功能、参考文件已上传都不等于功能已经实现。静态可见结构与动态操作待验证分开记录，不为核验自动生成视频。

用户明确要求先看方向时，在当次数量内选择能检验主要身体、个性化修饰、关键空间与交互物件的样张；不把任意“前几项”当全世界已经验证，也不强制所有项目增加固定数量的测试图或审批等待。方向变化保留旧成果追溯，只更新已授权依赖，不把历史合格资产当新方向母版，不用新命名重置同一需求重试次数。

发现多格配饰数量／侧别、物件结构或功能不一致，按原有限返修处理并真实标记。未锁定的纯美术差异若拟采用，先登记实际选择与适用范围；已经明确的侧别、剧情证据或数量不能静默接受错误。用户对整体方向的肯定不等于每项细节或剩余全剧已定版。
