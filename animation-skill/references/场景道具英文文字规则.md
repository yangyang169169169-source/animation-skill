# 场景、道具资产中的英文文字

步骤3、步骤4的规划、实际Prompt、生成及验收共用。场景与道具资产图允许出现符合剧情的英文文字，不因含文字自动判错，也不另设用户逐条批准或转后期的默认门槛。此许可不要求每张图都加字。

## 是否需要、写什么

- 从权威剧本、已确认的英文版本与本场／本物件的叙事用途决定文字。正文写明的门牌、店名、公告、信件、报告、合同、票据、包装、设备显示、证件或刻字，保留实际需要的内容；场景／物件的表达功能合理需要英文标识时，可作符合设定的简洁设计，并在现有规划中说明依据。不能为了填满墙面、让物件显专业或显高级，给每扇门、每张纸和每件物品随意加标签、营销口号或长篇说明。
- 有指定英文原文、名称或机构译名时原样使用，保持大小写、标点、数字和拼写。只有中文但含义明确时，沿项目已定译法准确转成英文并记录对应，不把翻译变成新增剧情。未给定且会影响剧情的人名、日期、金额、编号、诊断／检测结论、法律关系、权限或证据内容不能编造；只暂停真实依赖项或采用不暗示虚构结论的载体方案，其他独立工作继续。
- 文字表达服从当前剧情状态与观众知情顺序。未签署、已签署、未开封、被涂改、撕裂、遮挡与屏幕开关等分别准确；不能提前写出后续揭晓的身份、结论或秘密。只写本图中实际需要且应可见的部分，正文未要求显示整篇时不自行扩写文件。
- 用英文处理图内必要文字；中文工作备注、资产编号、文件名、Prompt标题与视图名称不印在画面里。参考图里的水印、字幕、无关品牌或随机标识不复制。剧情本有的标识与机构名称按实际设定处理，不被通用“无标识”后缀误删。

## 写入实际执行词

在现有场景／道具规划或调用表里记录文字用途、来源／已定译文、准确内容、位置／载体、可见状态及连续要求，不新增每条资产的固定字段。条目仍为原有两字段；规划说明用中文，必要的英文原文或目标字串可准确引用。

实际英文Prompt写清精确字串及其位置、顺序和载体，例如应位于门牌、纸面、屏幕、包装或刻印处，而不是悬浮字幕。字体／字形、工艺、尺寸、透视、颜色、光泽与时代地区、物件材质及当前状态相符；保证剧情关键部分在计划用途下可读，不让浅景深、反光、装饰或遮挡吞字。纸张版式和环境美感不能替代信息正确。

有需要时可用`Text, if required:`组织文字，但必须填完整准确的内容和呈现说明；没有文字需求时删除该栏或明确不添加无关文字。带字资产不得同时写`no text`、`no readable text`或其他一概禁字的冲突要求。无文字剧情需求的图可以使用只针对本图的禁字说明，不能把它当场景／道具全局默认。

## 准确性与连续性验收

实际看图，将应可见的英文与目标字串逐项核对：拼写、大小写、标点、数字、词序、语义和信息时机；再查是否漏字、多字、重复、乱码、错位、镜像或被无依据遮挡。机构／人名、日期金额及关键证据要特别核对，不以英文看起来像字、OCR输出正常或图片高清代替内容通过。

同地点反打、昼夜与必要状态派生保持标识名称、位置和朝向；同一文件／设备的文字变化按剧情发生、持续和消失，不能随着视角随机改词。正文要求损坏、遮挡或不可读时照设定呈现，不为验收擅自补回原本不可见的信息。

优先把需要的准确英文纳入本次内置生成与编辑，不因英文一概改成空白或强制后期。长篇排版、细小文字或真实工具限制使关键内容无法可靠实现时，可在既有授权内选择可控排版／合成，并记录实际完成范围；只有载体清楚不能把整张证据图标为完成。生成错字先定位受影响文字和载体，保正确结构与图像，在原有限返修次数内处理；没有可靠结果时报告具体缺口，不无限重画、不编造替代内容。

本规则只改变资产规划、写词与验收口径；更新Skill不生成图片、不重绘已确认资产或批量改历史Prompt。原生文件、清晰度、最终图目录及生成记录要求继续。
