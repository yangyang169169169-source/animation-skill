# 内容安全与叙事边界

本文件用于正式剧本的内容风险判断与最小修复。**尽量保留母本情节和对白，只将较高风险或原文明写风险内容的特写／直接展示提交用户判断。** 无风险、低风险及风格偏好不逐条报请确认。缩小的是需要用户判断的范围，不是审阅范围，也不是取消真实制作边界。

## 判断对象与依据

- 先看正文实际要求观众看到、听到什么，再结合行为目的、当事人行为能力、同意、叙事立场和后果。区分事件被提及、非露骨情节表达、直接展示与细节特写。
- 区分“反派正在作恶”和“作品在美化或教人实施伤害”。反派威胁、受害者叙述、非露骨犯罪背景本身不自动要求删掉事件；反派身份也不能为色情化侵害或极端血腥展示免责。
- 风险分级是本流程的工作标签，不等于平台官方处罚级别。分别说明是生成工具限制、平台禁发风险、年龄／推荐范围限制，还是项目风格偏好，不统称为“违规”。
- 需要作出具体平台规则判断时核查现行官方依据；无法核实时明确不确定性，不宣称必然过审或必然封禁。只核查影响实际处理的争议，不为每个普通打斗或接吻查一次规则。

平台对禁发、年龄限制和推荐资格有不同处理，虚构背景也不代表可以任意展示血腥细节。按具体呈现核查 [TikTok 敏感及成人主题规则](https://www.tiktok.com/community-guidelines/en/sensitive-mature-themes/)；涉及侵害、仇恨或未成年人安全时核查 [TikTok 安全与文明规则](https://www.tiktok.com/community-guidelines/en/safety-civility/)。不得将项目审美偏好写成这些规则的明文要求。

## 三档风险与报告阈值

| 标签 | 判定 | 处理 |
|---|---|---|
| S-P0 制作阻断 | 当前要求的具体表达明确触及适用工具／平台的禁止边界 | 必须告知具体证据、依据与最小可行方案；未解决前不制作该内容，用户保留原稿也不等于授权违规生成 |
| S-P1 情境与呈现风险 | 是否可制作或发布取决于表达、语境及展示尺度 | 只有实际较高风险，或原文明写风险内容的特写／直接展示时进入待决；轻微且无需调整的保留，不逐项核实 |
| S-P2 无／低风险及风格选择 | 未发现显著内容风险，或仅涉及人物伦理、审美、现实感等偏好 | 默认保留，不列待决，不阻塞步骤1 |

### 应当重点提交的情况

1. 性化未成年人、露骨性行为、色情化的非自愿性接触或性暴力、性剥削等真实高风险表达；不能把人物改称成年或移开镜头当作万能修复。涉及性内容而年龄实质不明时，需要核查，不能猜成年。
2. 将失去行为能力后的性行为、以资源或安全要挟亲密、明确拒绝后的侵害作为色情或浪漫奖励；需审查具体语境，不用“后来相爱”“有婚约”倒推当时同意。仅作为非露骨犯罪背景或受害者经历出现，不自动等同于需要重写整个情节。
3. 明写伤口、尸体损毁、血液细节、直接伤害过程等风险内容的特写或持续展示，以及以折磨、虐杀或大量血腥作为观赏重点。即使没有“特写”二字，实际描写仍构成较高风险，也要告知。
4. 性私密影像的露骨展示或剥削性传播、鼓励或具体指导严重伤害／自残、煽动针对受保护群体的暴力或仇恨等高风险表达。不得把所有反派侮辱或势利台词都归入这一档。
5. 其他有具体证据的较高风险，或会实质改变关键镜头的年龄／推荐限制。给出风险类型与范围，不把限制推荐等同于禁发，也不以“只影响推荐”为由隐去重大制作影响。

不是每段有这些题材的剧情都属于 S-P0。应定位实际越界表达，而不是要求剧本中一切伤害、犯罪或不道德行为的发生次数为零。

## 常见短剧表达：先看上下文

| 原文情况 | 默认判断与边界 |
|---|---|
| 成年角色短暂接吻、拥抱、双向暧昧、强势靠近 | 不按关键词列风险。已有清楚语境时不强加同意宣言、说明性对白；明确恐惧或严肃拒绝后仍发生性侵害，不能解释成调情 |
| 抓手腕、堵门、推挡、束缚 | 区分动作阻拦、救援、自卫、反派压迫与色情化胁迫；依据实际强度和后果判断，不自动删掉互动 |
| 救命、伪装或解除诅咒的功能性亲吻 | 结合紧迫目的、短促呈现及后续反应判断；不自动推定性同意，也不擅改具有关键因果作用的契约机制 |
| 酒精、魔法、信息素、诅咒 | 名词本身不定罪；核查是否真的剥夺选择并被用于色情化侵害。角色仍清醒自主与失去行为能力不可混为一谈 |
| 老板与助理、雇主与雇员恋爱，或成人之间的身份差 | 身份差本身不列风险。实际存在利益换亲密、拒绝报复或无法退出的依赖时才具体审查；不例行加 HR、合同、调岗或职业伦理说教 |
| 教学、医疗、监护等高度依赖关系 | 核查真实年龄、行为能力与依赖是否用于性剥削或胁迫；不只凭职位名改人物关系，也不忽略现实无法拒绝的情境 |
| 契约婚姻、先婚后爱、交易误会、非露骨成人关系背景 | 保留母本设定，不因不符合某种理想恋爱观提出整改；婚姻或契约不自动产生性同意 |
| 反派伤害、绑架、家庭压迫、威胁、误会与打脸 | 可以承担冲突和后果；重点判断实际展示及作品是否美化，不要求每场另加谴责台词或当场惩罚 |
| 普通打斗、少量虚构血迹、伤后反应、包扎与救援 | 没有明显风险展示要求时不逐条报请确认。少量血迹不等于大量血腥；仍需避免把一般动作自行扩写为细节伤害镜头 |
| 尸体被发现、受伤被提及、人物讲述过去遭遇 | 先分辨叙事事实与镜头展示；不能只见“尸体／伤口”就判必须改剧情，也不能把明确细节展示当成普通提及 |
| 成年人缩小、变形或童年非性化回忆；怀孕、分娩、普通医疗 | 不按关键词推定未成年人性化或色情；实际年龄、性化程度和画面细节才有判断意义 |
| 反派势利、嘲讽容貌或财富、冒犯性喜剧情节 | 不以个人道德偏好要求人物更体面；涉及真正仇恨煽动、羞辱性细节展示等时再按证据处理 |

## 最小修复顺序

1. **先判断是否真的需要改。** 无风险、风险较低且不影响制作的保留原文，不为假设“未来导演可能拍坏”给每处加警告。一般制作边界可统一交接一次，不变成全剧逐场整改表。
2. **需要调整时先保留事件，只改呈现。** 对风险伤害镜头，优先用动作前后、遮挡、声音、人物反应和结果替代细节展示；保留谁做了什么、伤势结果、误会、救援、反击、原对白与集尾打点。少量血迹和有剧情作用的打击不机械删去。
3. **明确风险特写先给具体方案。** 写清原镜头、建议镜头、对白是否保持、是否改变剧情信息；尚无授权时提交判断，不自行把核心镜头删掉。已有用户授权的统一呈现原则可直接应用并归类记录，不重复询问同类改法。
4. **呈现调整不足时才提出机制改法。** 如需改变关键行为是否发生、同意状态、人物关系、契约后果或后续揭秘，必须说明因果代价并先取得相应授权。不能把真实发生的事件擅改为误会、未遂或梦境，也不把伤害直接替换成无关追逐。
5. **修复后检查是否误伤剧情。** 保留人物立场、冲突强度、信息顺序与对白意图；不删除受害者质问、抗拒或后果以制造“没有风险”的假象。移开镜头仍不能解决的较高风险继续明示，不伪称已通过。

## 提交与复核

- 每条需要用户判断的风险项附：原文及集／场位置、具体展示或机制、风险级别与类型、最小拟改文本、对白／剧情影响。多处同一问题合并，列明适用场次。
- 未明确要求特写的一般伤害，仅因可以想象极端拍法，不构成新待决项。已经明确要求风险展示的镜头不能漏报。
- 对低风险和无需处理的桥段，不逐条附“建议保留，请确认”。完成后只说明实际审阅范围及有无需要判断的较高风险，不许保证“全剧零风险”。
- 真正未解决的 S-P0 内容暂停相应生成；较高风险实质选择未定时暂停其依赖的制作。已授权且不受影响的工作可以继续，不把风格偏好和普通反派行为变成全剧冻结条件。
